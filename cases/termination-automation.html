Case study · Service Desk Engineer III → Automation Engineer, V2X

From 16 hours of termination tickets to minutes of oversight

Replacing a manual, multi-ticket termination review with automated processing, then building the orchestration and audit-evidence pipeline around it in GCC High.

  • PowerShell
  • Azure Functions
  • Azure Automation
  • Hybrid Worker
  • Active Directory
  • Okta Workflows
  • Azure SQL
  • Power BI

The problem

Roughly 100 terminations a week came through as tickets, and each one needed a manual review across several tickets at about 10 minutes apiece: around 16 staff-hours every week spent on work that was repetitive, easy to get slightly wrong, and important to get exactly right.

Termination is also one of the most audited identity processes there is. It isn't enough to disable the account; you need to show when it happened and that it happened every time.

The approach

First, automate the review. As a Service Desk Engineer III, I replaced the manual multi-ticket review with automated processing, so people only look at the exceptions.

Then, orchestrate the action. As an Automation Engineer, I built PowerShell Azure Function Apps that take Okta-triggered termination requests, including privileged accounts, and hand them to Azure Automation runbooks on a Hybrid Worker, which can reach on-premises Active Directory.

  • No stored passwords. The Function authenticates with a managed identity and OAuth 2.0 bearer tokens, and starts runbook jobs through the Azure Resource Manager jobs API.
  • The runbook runs where AD lives. A Hybrid Worker executes the disable on-premises, so the cloud side never needs direct network access to domain controllers.
  • Evidence can't be edited after the fact. Evidence lands in immutable (WORM) Blob Storage. Event Grid and a Storage Queue feed an ingest Function that writes to Azure SQL, and Power BI reports on it with controlled access.

The result

~16 hrs/wkof manual review removed
Minutesof weekly oversight instead
Immutableevidence for ITGC and audit

The weekly termination load went from hours of ticket review to a few minutes of oversight. Each termination now follows the same path and leaves evidence that can't be quietly changed, which turns "prove it happened" from a scramble into a report.

What I'd tell the next engineer

  • Automate the boring 95% and route the rest to a person. The goal is fewer, better human decisions, not none.
  • Design the evidence with the automation. Adding audit trails afterwards is always harder and less trustworthy.
  • Prefer identities over secrets. Managed identity removed a whole class of credential-rotation problems.
